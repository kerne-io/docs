---
title: "Update user"
sidebarTitle: "Update user"
description: "Update a user's profile"
---

```typescript
const user = await kerne.users.update(userId, {
  first_name: 'Alicia',
  last_name: 'Doe',
});
```

Only succeeds for the user's own id, unless the caller is an admin - same rule as [`get()`](/sdks/server/users/get). `global_role`/`is_active`/`is_blocked` aren't settable through this method - those are stripped server-side unless the caller is already an admin, since letting a user promote or reactivate themselves would defeat the point of the flag (see [Authorization](/concepts/identity/authorization)).
