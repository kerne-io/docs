---
title: "Update user"
sidebarTitle: "Update user"
description: "Update a user's profile"
---

```typescript
const user = await kerne.users.update(userId, {
  first_name: 'Alicia',
  last_name: 'Doe',
});
```

Only succeeds for the user's own id, unless the caller authenticates with your secret key - same rule as [`get()`](/sdks/server/users/get). `is_active`/`is_blocked` aren't settable through this method - those are stripped server-side unless the caller is already an admin, since letting a user reactivate or unblock themselves would defeat the point of the flags (see [Authorization](/concepts/identity/authorization)).
