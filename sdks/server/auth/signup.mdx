description: "Register a new user"
---

Whether this succeeds depends on the tenant's registration mode - see [Registration modes](/concepts/identity/registration-modes). If invitations are required, pass `invitationToken` or `invitationCode`.

```typescript
const { token, refresh_token, user, expires_at } = await kerne.auth.signup({
  email: 'alice@company.com',
  password: 'a-strong-password',
  first_name: 'Alice',
  last_name: 'Doe',
  // invitationToken: '...',   // if the tenant requires an invitation
  // invitationCode: '...',
});
```

## Response

<ResponseField name="token" type="string" required>
  JWT access token.
</ResponseField>
<ResponseField name="refresh_token" type="string" required>
  Use this with [`refreshToken()`](/sdks/server/auth/refresh-token) to get a new access token once this one expires.
</ResponseField>
<ResponseField name="user" type="object" required>
  Minimal claim set: `{ id, email, role }`. For the full profile (`first_name`, `avatar`, ...), call [`users.get(user.id)`](/sdks/server/users/get).
</ResponseField>
<ResponseField name="expires_at" type="string" required>
  ISO timestamp for when `token` expires.
</ResponseField>
