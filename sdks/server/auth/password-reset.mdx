---
title: "Password"
description: "Reset and change passwords"
---

## Forgot password (unauthenticated)

```typescript
await kerne.auth.requestPasswordReset('alice@company.com');
// ... user clicks the link in their email ...
await kerne.auth.confirmPasswordReset(tokenFromEmail, 'a-new-strong-password');
```

Both always resolve without revealing whether the email exists - don't use success/failure here to check if an account exists.

## Change password (authenticated)

```typescript
await kerne.auth.changePassword({
  currentPassword: 'the-old-one',
  newPassword: 'a-new-strong-password',
});
```
