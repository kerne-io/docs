---
title: "Login"
description: "Authenticate a user with a password"
---

```typescript
const { token, refresh_token, user, expires_at } = await kerne.auth.login({
  email: 'alice@company.com',
  password: 'a-strong-password',
});
```

`login()` is a convenience wrapper around the unified [`token()`](/sdks/server/auth/refresh-token) exchange (`grant_type: 'password'`) - same response shape as [signup](/sdks/server/auth/signup): `{ token, refresh_token, user: { id, email, role }, expires_at }`.

<Note>
`K1005` (invalid credentials) and `K1011` (email not verified, if the tenant requires it) are the errors to handle explicitly here - see [Error codes](/concepts/error-codes).
</Note>
