---
title: "List waitlist"
sidebarTitle: "List waitlist"
description: "Retrieve waitlist entries (admin)"
---

Requires an admin caller.

```typescript
const { entries, pagination } = await kerne.waitlist.list({
  limit: 20,
  offset: 0,
  status: 'PENDING', // or 'INVITED' | 'REGISTERED'
});
```

`status` moves to `REGISTERED` automatically the moment that email successfully signs up - it's bookkeeping, not something that gates the signup itself. See [Registration modes](/concepts/identity/registration-modes) for how a waitlist entry actually becomes an invited user.
