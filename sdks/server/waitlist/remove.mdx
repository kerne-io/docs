---

Remove a user from the waitlist by their email address. Requires your secret key, or a JWT owner crossing into their own tenant.

```typescript
await kerne.waitlist.remove('user@example.com');
```

Unlike `join()`/`list()`, this call also requires the Waitlist feature on your own Kerne plan - if your plan doesn't include it, it's denied with `K5002` even for an admin caller.

## Errors

| Code | Status | Description |
|------|--------|-------------|
| `K4005` | 404 | Waitlist entry not found |
| `K3002` | 403 | Insufficient permissions |
| `K5002` | 402 | Waitlist not included in your Kerne plan |
