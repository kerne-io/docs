---
title: "Join waitlist"
sidebarTitle: "Join waitlist"
description: "Add a user to the waitlist"
---

```typescript
const result = await kerne.waitlist.join({
  email: 'alice@company.com',
  name: 'Alice Doe',
  metadata: { referral: 'twitter' }, // optional, stored as-is
});
// { success: true }
```

Always resolves `{ success: true }` - whether the email was newly added,
already on the waitlist, or already belongs to a registered account are
deliberately indistinguishable. This is a public, unauthenticated route, so
the response never reveals which emails already exist in your system.

<Note>
  No confirmation email is sent when someone joins the waitlist - the first
  email they'll receive is the real invitation, sent when you invite them.
</Note>
