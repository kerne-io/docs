    Hooks and guard components for session state and entitlement checks. Works in any React app (Next.js, Vite, Remix, ...) - nothing Next.js-specific.
  </Card>
</CardGroup>

The client SDK never holds a secret key - it authenticates as the logged-in user (JWT), scoped to what that user is allowed to see about themselves. Anything that needs to act on another user's behalf, or touch the catalog, belongs in [`@kerne/server`](/sdks/server/overview) instead.
