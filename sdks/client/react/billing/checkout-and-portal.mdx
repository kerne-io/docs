---
title: "Checkout & portal"
description: "Send the user to a hosted checkout or billing portal"
---

```tsx
import { useCheckout } from '@kerne/react';

function UpgradeButton({ planPriceId }: { planPriceId: string }) {
  const { openCheckout } = useCheckout();

  return (
    <button onClick={() => openCheckout(planPriceId, { successUrl: '/billing/success' })}>
      Upgrade
    </button>
  );
}
```

<Warning>
The first argument is a **`plan_price_id`** (a specific billing variant - monthly vs. yearly), not a plan id.
</Warning>

`openCheckout()` redirects the browser directly (`window.location.href = url`). If you want the URL instead - to open in a new tab, or handle the redirect yourself - use `createCheckout()`, which returns the URL without navigating:

```tsx
const { createCheckout } = useCheckout();

const checkoutUrl = await createCheckout(planPriceId);
```

The billing portal works the same way, via `usePortal()`:

```tsx
import { usePortal } from '@kerne/react';

const { openPortal, createPortal } = usePortal();

await openPortal(); // redirects the browser
const portalUrl = await createPortal(); // or get the URL yourself
```

## Where the redirect goes if you don't pass a URL

`successUrl`/`cancelUrl`/`returnUrl` above are all optional. Left unset, each resolves independently through your tenant's configured `app_url` before falling back to a Kerne-hosted page - see the server SDK's [Checkout docs](/sdks/server/billing/checkout#where-the-redirect-goes-if-you-dont-pass-successurlcancelurl) for the exact resolution order and how to configure `app_url`.

## The caller's own subscription

The reactive hook covers most cases:

```tsx
import { useSubscription } from '@kerne/react';

const { subscription, isActive, isLoading } = useSubscription();
```

For an imperative, one-off read, use the underlying client directly:

```tsx
import { useClient } from '@kerne/react';

const client = useClient();
const sub = await client.getSubscription(); // null if none, or scoped to a product slug: getSubscription('acme')
```
