## Waitlist

```tsx
import { useState } from 'react';
import { useWaitlist } from '@kerne/react';

function WaitlistForm() {
  const { join } = useWaitlist();
  const [email, setEmail] = useState('');
  const [joined, setJoined] = useState(false);

  if (joined) return <p>You're on the list.</p>;

  return (
    <form
      onSubmit={async (event) => {
        event.preventDefault();
        await join({ email });
        setJoined(true);
      }}
    >
      <input
        type="email"
        value={email}
        onChange={(event) => setEmail(event.target.value)}
        required
      />
      <button type="submit">Join the waitlist</button>
    </form>
  );
}
```

`join()` also takes `name` and `metadata`, and always resolves `{ success: true }`. `@kerne/react/ui` has a ready-made `<WaitlistForm>`. Listing and removing entries is done from your backend: see [Waitlist](/sdks/server/waitlist-invitations#waitlist).

## Invitations

Check an invitation before showing your sign-up form:

```tsx
import { useInvitation } from '@kerne/react';

function SignUpPage({ inviteToken }: { inviteToken?: string }) {
  const { result, isLoading } = useInvitation({ token: inviteToken });

  if (isLoading) return <Spinner />;
  if (!result?.valid) return <InvalidInvitation />;
  return <RegisterForm invitationToken={inviteToken} />;
}
```

For a code, pass `{ code }` and gate on `result.canUse`: a code can be valid but used up. Then pass the same token or code to [`register()`](/sdks/client/react/authentication#log-in-and-register). Invitations are created and revoked from your backend: see [Invitations](/sdks/server/waitlist-invitations#invite-by-email).
