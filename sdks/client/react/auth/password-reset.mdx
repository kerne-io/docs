## Change password (logged in)

Exposed directly on `useAuth()` - no server round-trip of your own needed:

```tsx
import { useAuth } from '@kerne/react';

function ChangePasswordForm() {
  const { updatePassword } = useAuth();

  await updatePassword({ currentPassword, newPassword });
}
```

## Forgot password (logged out)

<Note>
Not wrapped by this SDK yet - `requestPasswordReset()`/`confirmPasswordReset()` only exist on the [server SDK](/sdks/server/auth/password-reset) today. Proxy them through your own API route.
</Note>

```typescript
// your own backend route, using @kerne/server
import { kerne } from '@/lib/kerne';

export async function POST(req: Request) {
  const { email } = await req.json();
  await kerne.auth.requestPasswordReset(email);
}
```

```tsx
// your React form calls that route
async function handleSubmit(email: string) {
  await fetch('/api/auth/request-reset', {
    method: 'POST',
    body: JSON.stringify({ email }),
  });
}
```

The confirm step (`confirmPasswordReset(token, password)`) works the same way - read the token from wherever your reset link lands, POST it to your own route, which calls the server SDK.
