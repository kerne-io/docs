---
title: "Register"
description: "Create a new user account"
---

```tsx
import { useAuth } from '@kerne/react';

function RegisterForm() {
  const { register } = useAuth();

  await register({ email, password, name }); // name is split into first_name/last_name
}
```

Whether this succeeds depends on the tenant's [registration mode](/concepts/identity/registration-modes) - if invitations are required, [validate the token/code](/sdks/client/react/invitations) before showing this form at all, rather than letting the user hit a rejection here.

Same response shape as [login](/sdks/client/react/auth/login) - use `useAuth().user` for the full profile, not the return value of `register()`.

## Errors

| Code | Meaning |
|------|---------|
| `K1001` | Registration is disabled for this app. |
| `K1002` | Maximum user limit reached. |
| `K1008` | Email already registered. |
| `K1010` | Password doesn't meet the strength requirement. |
