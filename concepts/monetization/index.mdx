Here is the line that causes the trouble:

```typescript
if (user.plan === 'pro') {
  showAdvancedAnalytics();
}
```

It works. It keeps working right up until the day someone decides Advanced Analytics belongs on a new Enterprise tier — and then you go hunting for every place that name was written, in every service, and redeploy all of them to make a pricing decision take effect.

The plan name was never the point. What you actually meant was *"is this customer allowed to see advanced analytics?"* — and that's a different question, with an answer that can change without your code changing.

## The shape Kerne gives it

A plan grants **entitlements**: named capabilities, each with a value. Your code asks about the capability, never about the plan:

```typescript
if (await kerne.allows('advanced_analytics', { subject: user.id })) {
  showAdvancedAnalytics();
}
```

Move that feature to a different tier, raise its limit, put it behind a higher price, hand it to one customer as an exception — this line does not change. It resolves against whatever the rules currently say, every time it runs.

That indirection is the whole trade: you give up naming plans in code, and you get pricing you can change without a deploy.
