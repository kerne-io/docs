---
title: 'Your first access decision'
description: 'Create an offer, check it from your code, then change it'
---

Five steps, no payment provider needed. At the end, you'll change what a customer gets without touching your code.

## 1. Create a product

In the dashboard, open **Catalog**, click **New product**, then open it. The editor first asks for a billing label, such as "Monthly": click **Create the first label**. You'll put prices on it later.

A new product comes with a plan called **Default**. Every customer is on it until they subscribe to something else.

## 2. Add a feature

Click **+ feature** and choose **BOOLEAN**. Click **New feature** to open it, and set its **Key** to `export_pdf`.

Turn the feature on in the **Default** column. Then click **Save** and choose **Update this offer**.

Your code will ask about `export_pdf`. It never asks which plan someone is on.

## 3. Install the SDK

```bash
npm install @kerne/server
```

```typescript
// lib/kerne.ts
import { Kerne } from '@kerne/server';

export const kerne = new Kerne({
  appId: process.env.KERNE_APP_ID!,
  secretKey: process.env.KERNE_SECRET_KEY!,
});
```

Both values are in **Settings → API keys**. The secret key is shown only once: if you didn't copy it, rotate it. It can act for any customer, so keep it on your server.

## 4. Check access

```typescript
export async function exportPdf(req, res) {
  const allowed = await kerne.allows('export_pdf', { customer: req.user.id });
  if (!allowed) return res.status(403).json({ error: 'upgrade_required' });

  return res.json(await renderPdf());
}
```

`customer` is your own id for whoever you bill: a user, or a company. Kerne doesn't need to know it in advance. An id it has never seen is on **Default**, so this returns `true`.

## 5. Change the offer

Turn `export_pdf` off in the **Default** column, then **Save → Update this offer**.

Call your route again: it answers `403`. You changed what your customers get, and deployed nothing.

**Update this offer** reaches everyone on the plan, which is what you want on a free plan. On a plan people pay for, you can choose **Start selling to new subscribers** instead: new buyers get the change, and everyone already subscribed keeps what they bought. See [Offers and versions](/concepts/monetization/products-and-plans).

## If it doesn't work

| What you see               | Likely cause                                                       |
| -------------------------- | ------------------------------------------------------------------ |
| `allows()` returns `false` | The feature is off on the customer's plan, or the edit isn't saved |
| `401 Unauthorized`         | Wrong secret key, or a key from another project than the app id    |
