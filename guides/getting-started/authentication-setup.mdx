Every project comes with a hosted portal: sign-in, sign-up and password reset pages with your logo and colors. Send people there, or build the forms in your app.

## 1. Decide who can sign up

New projects are invite only. To let anyone create an account, go to **Settings → Authentication** and set **Who can sign up** to **Open**. See [Registration modes](/concepts/identity/registration-modes).

## 2. Add the provider

```bash
npm install @kerne/react
```

```tsx
// app/providers.tsx
import { KerneProvider } from '@kerne/react';

export function Providers({ children }) {
  return <KerneProvider appId={process.env.NEXT_PUBLIC_KERNE_APP_ID!}>{children}</KerneProvider>;
}
```

The app id is safe in the browser. Your secret key is not: it stays on your server.

## 3. Send people to sign in

```tsx
import { useAuthConfig, resolvePortalAuthUrl } from '@kerne/react';

function SignInLink() {
  const { config } = useAuthConfig();
  const url = resolvePortalAuthUrl(config?.portal_url, 'sign-in');

  if (!url) return null;
  return <a href={url}>Sign in</a>;
}
```

Pass `'sign-up'` for the sign-up page. After signing in, people come back to **Send users back to**, or to your **Production URL** if that's empty, both in **Settings → General**. `KerneProvider` picks up their session on its own: see [Session handoff](/sdks/client/react/authentication#session-handoff) to handle a failed one.

Password reset, email verification and magic link emails always open the hosted portal, even if you build your own forms.

## 4. Use the session

```tsx
import { useAuth, Authenticated } from '@kerne/react';

function Account() {
  const { user, logout } = useAuth();
  return <button onClick={logout}>Sign out {user?.email}</button>;
}

<Authenticated fallback={<SignInLink />}>
  <Account />
</Authenticated>;
```

`<Authenticated>` shows its `fallback` while the session loads too. If that flash matters, check `isLoading` from `useAuth()` yourself.

## Or build your own forms

```tsx
const { login, register } = useAuth();

await login({ email, password });
await register({ email, password, name: 'Alice Doe' });
```

`register()` fails with `K1001` when sign-up isn't open to this person, and `K1008` when the email is taken. Every code is in [Authentication](/sdks/client/react/authentication#log-in-and-register).

For ready-made screens instead, `<AuthFlow>` from `@kerne/react/ui` covers sign-in, sign-up and password reset in one component: see [Prebuilt screens](/sdks/client/react/ui/overview).
