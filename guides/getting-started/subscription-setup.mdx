## 1. Connect Stripe

In the dashboard, go to **Settings → Payment provider** and click **Connect** next to Stripe. Authorize Kerne on Stripe and you come back connected.

Stripe is the only provider you can connect today. If you already have subscribers there, click **Import existing subscriptions** once connected.

## 2. Price a plan

In **Catalog**, open your product and click **+** to add a plan. Name it, type its price in the plan's column, then **Save → Update this offer**. Kerne creates the price at Stripe, in your Stripe account's currency.

An empty price means the plan isn't sold on that billing label, and `0` means it's free. To sell yearly as well as monthly, add a second label.

## 3. Send the customer to checkout

From your backend:

```typescript
const { url } = await kerne.billing.checkout('pro-monthly', {
  customer: user.id,
  email: user.email,
});

res.redirect(303, url);
```

`pro-monthly` is the price's slug: the plan's slug, then the label's. Pass `email` unless Kerne already has one for this customer. A customer Kerne doesn't know yet is created here.

With Kerne sign-in, React can start it from the browser for the signed-in user:

```tsx
import { useCheckout } from '@kerne/react';

function UpgradeButton() {
  const { openCheckout } = useCheckout();
  return <button onClick={() => openCheckout('pro-monthly')}>Upgrade to Pro</button>;
}
```

For a whole pricing page, [`<PricingTable>`](/sdks/client/react/ui/pricing-table) renders your plans and starts checkout for you.

## 4. After payment

The customer lands on your hosted portal, which sends them back to **Send users back to**, or to your **Production URL** if that's empty. Both are in **Settings → General**.

The subscription starts when Stripe confirms the payment, sometimes a few seconds after the customer is back. Don't assume it exists on the first page load.

## 5. Let customers manage their subscription

```typescript
const { url } = await kerne.billing.portal({ customer: user.id });
res.redirect(303, url);
```

This opens Stripe's billing portal: card, invoices, cancellation. In React, `usePortal().openPortal()` does the same for the signed-in user.
