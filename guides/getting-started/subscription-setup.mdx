This guide walks through connecting a payment provider, configuring a plan, and implementing checkout - creating the actual product/plan/price catalog is a dashboard task, not something your app's code does at runtime.

## Prerequisites

- A Kerne app
- A Stripe account
- Your app already configured with authentication - see [Authentication setup](/guides/getting-started/authentication-setup)

## 1. Connect a payment provider

In the Kerne dashboard: **Settings → Billing → Connect Stripe**, then complete the OAuth flow. Use test mode during development.

<Note>
Already connected to Polar? That connection keeps working exactly as before - checkout, webhooks, and the portal are unaffected. Just don't delete the webhook endpoint Kerne created in your Polar organization: Polar gives Kerne no notification when that happens, so billing sync silently stops until you click resync (the refresh icon next to your Polar connection in the dashboard), which detects the missing endpoint and recreates it.
</Note>

## 2. Create a product and plan

This is a dashboard action, not an SDK call - catalog configuration (products, plans, prices) is control-plane: it's you configuring your own SaaS, not something your running app does. In the dashboard: **Billing → Products** → create a product → add a plan with pricing.

## 3. Display pricing

`kerne.billing.plans()` is the one catalog read exposed to your app - public, meant for a pricing page:

```typescript
// Anywhere - this route needs no session, just x-app-id
const plans = await kerne.billing.plans('acme'); // product slug or id
```

`price.interval` is `{count}{unit}` (`unit` is `D`, `M`, or `Y` - e.g. `"1M"`, `"3M"`, `"1Y"`), not a word - never render it directly to an end user:

```tsx
import { useCheckout } from '@kerne/react';

const INTERVAL_UNIT = { D: 'day', M: 'month', Y: 'year' } as const;

function formatInterval(interval: string): string {
  const count = parseInt(interval, 10);
  const unit = INTERVAL_UNIT[interval.slice(-1) as keyof typeof INTERVAL_UNIT];
  return count === 1 ? unit : `${count} ${unit}s`;
}

function PricingPage({ plans }) {
  const { openCheckout } = useCheckout();

  return (
    <div>
      {plans.map((plan) => (
        <div key={plan.id}>
          <h3>{plan.name}</h3>
          {plan.prices.map((price) => (
            <button key={price.id} onClick={() => openCheckout(price.id)}>
              Subscribe - {price.amount / 100} {price.currency}/{formatInterval(price.interval)}
            </button>
          ))}
        </div>
      ))}
    </div>
  );
}
```

<Warning>
Checkout takes a **price** id (`plan.prices[i].id`), not the plan's own id - a plan can have several prices (monthly, yearly).
</Warning>

## 4. Implement checkout

```tsx
import { useCheckout } from '@kerne/react';

function UpgradeButton({ planPriceId }: { planPriceId: string }) {
  const { openCheckout } = useCheckout();

  return (
    <button
      onClick={() =>
        openCheckout(planPriceId, { successUrl: '/billing/success', cancelUrl: '/pricing' })
      }
    >
      Upgrade
    </button>
  );
}
```

## 5. Handle success

The subscription is created once the provider confirms payment (asynchronously - not necessarily the instant the browser lands back on your success URL):

```tsx
function SuccessPage() {
  return (
    <div>
      <h1>Welcome to Pro!</h1>
      <p>Your subscription is now active.</p>
    </div>
  );
}
```

## 6. Provide a billing portal

```tsx
import { usePortal } from '@kerne/react';

function BillingSettings() {
  const { openPortal } = usePortal();
  return <button onClick={() => openPortal('/settings')}>Manage subscription</button>;
}
```
