---
title: 'Implement invite-only SaaS'
description: 'Let people in by invitation only'
---

New projects are invite only: nobody can create an account without an invitation. Check it under **Settings → Authentication → Who can sign up**. Kerne enforces it on its side, so a sign-up request that skips your frontend still needs a valid invitation.

## Invite someone by email

In the dashboard, go to **Waitlist → Invitations → Invite by email**. Or from your backend:

```typescript
await kerne.invitations.createToken({ email: 'alice@company.com' });
```

Kerne emails the invitation. The link opens sign-up on your hosted portal, works for that email address only, and expires after 7 days. Inviting the same address again replaces an unused invitation: that's how you resend one.

## Hand out a code

In the dashboard, go to **Waitlist → Invitations → Create invite code**. Or from your backend:

```typescript
const { code } = await kerne.invitations.createCode({
  maxUses: 500, // 1 by default, up to 1,000
  expiresAt: '2026-12-31T23:59:59.000Z', // omit for no expiry
});
```

Anyone with the code can sign up until it's used up or expires. Share it however you like: a launch email, a landing page.

## Sign up with an invitation

People who follow an emailed invitation sign up on your hosted portal, so there's nothing to build. With your own forms, pass the code or the token to `register()`:

```tsx
const { register } = useAuth();

await register({ email, password, invitationCode: code });
```

To check a code before showing the rest of the form, use `useInvitation({ code })` in React or `kerne.invitations.validateCode(code)` on your server. Neither needs a secret key.

A refused sign-up fails with `K1001`, whether the invitation is missing, invalid, used up or expired. If the email already has an account, the error is `K1008`: send them to sign in instead.

## Let people in from the waitlist

Joining the waitlist doesn't let anyone in by itself. When you're ready, select entries under **Waitlist** and click **Invite**: each one gets an emailed invitation.
